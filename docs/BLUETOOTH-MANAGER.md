# 在平板上配对蓝牙键盘和鼠标

1. 在 Xfce 应用菜单的“设置”中打开“蓝牙管理器”。将配件切到配对模式，在平板上轻点“查找”。
2. 在列表中轻点自己的键盘或鼠标，再点工具栏的“配对”。若键盘没有显示屏，平板可能会显示六位数字。在外接键盘上依次输入这六位数字，保留开头的零，然后按回车。若两端都显示数字，核对一致后点“确认”。部分鼠标会直接完成配对。
3. 对准备长期使用的配件，选中该行后点“信任”。以后要撤销信任，选中同一行再点“取消信任”。需要手动重连时，在设备菜单中选“连接”。

如果查找或配对失败，界面下方会显示摘要。点“更多”可滚动查看完整原因，关闭详情即可返回设备列表。配对期间取消或拒绝后，可让配件重新进入配对模式，再从列表选择它。
