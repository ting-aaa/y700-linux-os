# dev12.13 镜像与验证记录

国行 Y700 二代 TB320FC_PRC 的 dev12.13 安装包预装相机方向修复、触屏蓝牙管理器、单次点选中文候选词和顶栏快捷设置。默认内核、设备树、initrd 和备用 120 Hz 内核沿用 dev12.12 已验证的版本。通用根等待新机主首次设密。软件包中没有参考平板的个人账户、蓝牙地址或传感器校准。[构建与通用身份检查](DEV12.13-ROOT.md) · [单机数据来源](DEV12.12-PER-UNIT.md)

## 从主包启动桌面

从最终 TAR 解包后，ARM64 虚拟 U-Boot 通过 EFI 启动根系统。第一次用触屏故意输入两次不同的新密码，账户仍锁定；两次一致后用屏幕键盘登录 Xfce。第一次关机后，用另一个虚拟机进程从同一份临时可写磁盘冷启动，直接用原密码登录。两次的 Linux 启动 ID 不同，实际根、EFI 和 1,241 项包清单一致。

两次登录后，顶栏快捷设置均由 Xfce 自动启动。通过 Type-B 触点轻点托盘、打开和关闭自动旋转，再收起面板；相机选择器的「取消」和图形设置也都接受触屏输入。Parole 打开 H.264 样片，两次均显示三组不同的预期色块。虚拟机使用软件解码。退出后复核全部输入摘要不变，精简收据 `out/dev12.13-board-verified/desktop.txt` 的 SHA-256 为 `2232027557b74464739b021e6b0587379dc143b1c8f3b771047491f16b8ba3a3`。[复现方法](../tests/combined-efi/README.md)

## 参考平板

在运行日常 dev12.11 内核的平板上，通过 USB 把发行包的压缩根传入 RAM，用时 55 秒。平板校验了 6 GiB 原始根和 1,241 项包记录，在独立的 2560 × 1600、200% 缩放 Xfce 会话中启动了屏幕键盘和顶栏快捷设置。中英文相机菜单在隔离的虚拟三镜头后端均默认选中主摄。测试结束后，日用席位、网络、存储及摄像头电源状态均已复核。[实机 RAM 测试](../tests/tablet-desktop-ram/README.md)

内置日用系统上的后置主摄预览由机主另行复看，确认原先上下左右倒置的问题已修复。三镜头、四种屏幕方向的 JPEG 像素方向另有合成标靶测试。后置主摄实景自动合焦、真实蓝牙键鼠绑定与输入，以及 dev12.13 开机进入物理显示屏，仍待独立验证。[相机方向](CAMERA-ORIENTATION.md) · [后摄对焦](CAMERA-FOCUS-PROBE.md) · [蓝牙无线链路](BLUETOOTH-HID-RADIO.md)

## 从 USB 启动独立 RAM 诊断

dev12.13 可以从封存 EFI 和根镜像构建禁用 UFS、SD 的 RAM 启动包，再拆出小 initrd 与独立的 SquashFS 载荷。对焦附件检查系统版本和包清单，保留单轮授权、只传聚合测量值和正常重启的期限。版本专用附件 SHA-256 为 `b95ffa6ee14db058903c38a7c1bf892883dff150bb1dbed7e4638136f0db21d2`。五文件清单 SHA-256 为 `c7e5c6a5cfc795c25bd54940b8f4f1fea0e457cafb02f6e17ca3dc6914fc608f`。[RAM 构建器](../scripts/build-ram-trial.sh) · [接收器构建器](../scripts/build-ram-receiver.sh) · [版本专用附件](../tests/ram-af-acm/dev12.13-attachment.sh)

ARM64 虚拟机从小 initrd 实收 1,353,732,096 字节，核对载荷 SHA-256 `1e8d32f9db603ff91c13b4666e78ce2d8af3355cf7e8fa2426339b4e13743ef2`。进入 RAM 根后，诊断进程报告无持久盘、无交换区，完成了一次合成图像的测量、断线重取收据和清理。[主机接管及恢复步骤](../tests/uboot-ram-stage/README.md#dev1213-正常重启时接管串口)

实体国行平板首次串口接管超时。延长等待窗口后，主机在正常重启时接管了 U-Boot，退出 EFI 菜单并通过三处 RAM 校验。UFS 和 SD 控制器均已禁用。平板经 USB 收到及核对了同一份载荷，从 dev12.13 内核与 RAM 根启动。后置主摄取得 664 帧，预览中央亮度接近黑色，未达到触发对焦的条件。平板已正常回到内置 dev12.11，两层 ext4 的写入、同步与直接读回均通过。此次进入的是板端诊断服务；实体屏首次图形登录仍待验证。[后摄测量与复机记录](CAMERA-FOCUS-PROBE.md#dev1213-physical-preview-before-autofocus)
