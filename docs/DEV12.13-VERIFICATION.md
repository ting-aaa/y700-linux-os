# dev12.13 镜像与验证记录

国行 Y700 二代 TB320FC_PRC 的 dev12.13 安装包预装相机方向修复、触屏蓝牙管理器、单次点选中文候选词和顶栏快捷设置。默认内核、设备树、initrd 和备用 120 Hz 内核沿用 dev12.12 已验证的版本。通用根等待新机主首次设密。软件包中没有参考平板的个人账户、蓝牙地址或传感器校准。[构建与通用身份检查](DEV12.13-ROOT.md) · [单机数据来源](DEV12.12-PER-UNIT.md)

主包在产品树的 `out/dev12.13-board/`。从最终 TAR 实际解开三个文件，逐一校验全部字节。两次从锁定的内核、设备树和 dev12.11 EFI 分区构建新版双菜单 EFI 分区，结果逐字节一致。组包时从 ext4 内独立查询 dpkg 状态并核对 1,241 项，与镜像内部账本和参考平板日用系统升级后的同一批包版本一致。[解包步骤](DEV12.13-IMAGE.md) · [EFI 构建器](../scripts/build-camera-esp.sh) · [整包构建器](../scripts/package-board-image.sh)

试用卡在 `out/dev12.13-sd/`。双内核各自在 ARM64 虚拟机中从卡启动，核对挂载及软件包后正常关机。缺卡、旧版卡和错误卡 EFI 序列号均触发重启，下一次固件启动自动回到内置默认项。实体卡槽启动仍待实物验证。[试用卡与启动测试](DEV12.13-SD.md)

## 参考平板

在运行日常 dev12.11 内核的平板上，通过 USB 把发行包的压缩根传入 RAM，用时 55 秒。平板校验了 6 GiB 原始根和 1,241 项包记录，在独立的 2560 × 1600、200% 缩放 Xfce 会话中启动了屏幕键盘和顶栏快捷设置。中英文相机菜单在隔离的虚拟三镜头后端均默认选中主摄。测试结束后，日用席位、网络、存储及摄像头电源状态均已复核。[实机 RAM 测试](../tests/tablet-desktop-ram/README.md)

内置日用系统上的后置主摄预览由机主另行复看，确认原先上下左右倒置的问题已修复。三镜头、四种屏幕方向的 JPEG 像素方向另有合成标靶测试。后置主摄实景自动合焦、真实蓝牙键鼠绑定与输入，以及 dev12.13 开机进入物理显示屏，仍待独立验证。[相机方向](CAMERA-ORIENTATION.md) · [后摄对焦](CAMERA-FOCUS-PROBE.md) · [蓝牙无线链路](BLUETOOTH-HID-RADIO.md)
