# Y700 Linux OS

为联想拯救者 Y700 二代（2023，**TB320FC / TB320FC_PRC，SM8475**）开发可日常使用的原生 Linux 桌面系统。

目标是完整桌面发行版的体验：触摸和屏幕键盘、可靠网络、硬件图形加速、传感器与旋转、音频与蓝牙、休眠与充电，以及可维护的更新、回滚和恢复。当前以 Debian 13 ARM64 为用户空间，基于 Asphalt 板级支持推进。

**当前状态：开发基线，尚非产品级发行版；没有对公众发布可直接刷机的稳定镜像。** 此仓库承接一台国行 16 GiB / 512 GB 设备的前期实机验证，不代表其他容量、区域底包或 Y700 其他代际兼容。

## 在平板桌面上操作

打开「设置管理器 → 硬件」，可以找到内屏亮度、平板显示缩放和平板屏幕旋转。dev11.1 在实机的中英文 Xfce 环境都显示了这三个入口。亮度可用加减按钮微调，也可直接选择百分比或恢复打开时的值。[亮度操作与实测](docs/BRIGHTNESS.md)

- **首次开机**　组合开发镜像的本地账户名为 `y700`。首次开机在屏幕键盘上输入两遍新密码，随后在图形登录界面使用同一密码进入 Xfce。已在同一份 ARM64 镜像里走通全程，平板内置屏的实际触点和方向仍待验证。[首次设密](docs/FIRSTBOOT-TOUCH.md) · [图形登录](docs/WARM-GREETER.md)
- **锁屏和解锁**　测试平板已安装触屏锁屏组件；下次登录 Xfce 后会自动启用。点顶栏右侧的账户菜单，选择「锁定屏幕」。触碰锁屏画面，用下方的屏幕键盘输入当前账户密码，再点「解锁」，即可回到原先打开的应用。接有键盘时也可以用 Ctrl+Alt+L 锁屏。默认空闲时间为 5 分钟，可在「设置 → 屏幕保护程序」调整。[触屏解锁验证](docs/SCREEN-LOCK.md) · [构建与安装](docs/BUILD.md#touchscreen-session-lock)
- **调整缩放**　dev9 在单独使用原生分辨率内屏时，为新 Xfce 用户默认选择 200%。已有用户明确选择的比例继续生效。「设置 → 平板显示缩放」可切换 100% 或 200%，部分应用需重新打开。[桌面与应用缩放](docs/PLATFORM-BUILD.md) · [浏览器手势](docs/TOUCH-GESTURES.md)
- **调整音量或静音**　点顶栏右侧、系统托盘旁的扬声器图标。拖动第一行的播放音量滑块，点同一行的开关可静音或恢复。实机在 200% 缩放下给这个图标留出了 128 × 128 像素的点按区域。[音量面板实测](docs/PANEL-AUDIO.md)
- **连接外接屏时的触控**　dev10 会在桌面尺寸改变时重新对齐内屏触控。ARM64 双屏测试中，同一个触点在旧版落到了右侧外屏的第 2,112 像素，修复后落在内屏的第 1,056 像素。拔除外屏后也能自动恢复。真实 USB-C 显示器的输出和触点仍待验证。[双屏触控验证](tests/display-touch-topology/README.md)
- **输入中文和切换桌面语言**　点面板的输入法图标，选择「Chinese – Intelligent Pinyin」。点入文本框后用屏幕键盘拼写，点候选词前的编号上屏。若拼音仍在编辑，再点一次编号，空格也可选中当前候选。在 Chromium 里切换输入法后，如键盘收起，点一下其他控件再点回输入框即可。用「设置 → Display language」选择简体中文或英语，下次登录生效。完整镜像在 ARM64 EFI 测试中先后登录了英文和中文桌面。[中文输入实测](docs/CHINESE-INPUT.md)
- **锁定屏幕方向**　「设置 → 平板屏幕旋转」默认锁定当前方向。启用自动旋转后，dev12.6 会在 Xfce 锁屏时暂停，解锁后重新读取方向。实机在一次 5.018 秒的传感器 DSP 启停中读到了加速度、角速度、磁场、环境光、接近、罗盘和保护套霍尔。桌面普通账户也已在实机读到屏幕朝上、17.74 lux 和接近状态为远。ARM64 模拟环境中，四个方向稳定后，触点都落在预期位置。真实平板竖起和翻转时的界面方向、手指落点及开合盖响应仍待实测。[七通道读数](docs/SSC-TRIAL.md#seven-channel-physical-survey) · [桌面旋转](docs/CAMERA-SENSORS.md#xfce-screen-rotation)
- **保留本机传感器校准**　SSC 0.1.1 首次初始化时，从这台平板的内部 UFS 只读导入出厂校准。本机实测合并得到 375 组配置，重复初始化保留了已有状态。通用镜像随附板级默认值，每台平板在本地完成导入。已装 dev12.4 的设备可以单独升级传感器组件到 0.1.3；测试平板已完成这一更新。[校准来源与验证](docs/SSC-CALIBRATION.md) · [离线升级与回滚](docs/SSC-SERVICE.md)
- **选择 Wi-Fi**　点面板上的网络图标，展开「Available networks」（可用网络）。实机普通用户的菜单里显示了当前网络和另外 6 个可用网络。「Network Connections」（网络连接）列出 2 个已保存配置。WPA3 密码输错时，可以打开「设置 → 高级网络配置」，编辑已保存连接的 Wi-Fi 安全密码并保存。独立 ARM64 测试中原连接随后取得了 DHCP 地址。[选网验证](docs/WIFI-CHOOSER.md)
- **添加蓝牙键鼠**　将外设置于配对模式，再打开 Blueman 管理器选择设备。平板显示给外接键盘的六位数字时，在外接键盘上输入。如果对话框要求输入配件提供的 PIN，可用平板屏幕键盘输入，再点回车提交。测试平板已安装 Blueman y7002，下次正常登录后生效。实机已识别无线键鼠报告，隔离桌面验证了六位码显示及确认按钮。dev12.5 的 ARM64 虚拟设备上，低功耗与经典蓝牙键盘都能在普通应用中输入和编辑短句，重连后继续打字，鼠标的点击、移动和滚轮也有效。实机日常键鼠仍待配件验证。[屏幕键盘与外接键鼠](docs/PERIPHERALS.md#screen-keyboard-with-external-accessories) · [实机无线](docs/BLUETOOTH-HID-RADIO.md) · [配对界面](docs/BLUEMAN-PAIRING.md) · [输入与重连](docs/BLUETOOTH-VIRTUAL.md)
- **拍照**　从 Xfce 的图形菜单打开「Y700 相机」。测试机已升级到 `y7004`，中文界面可以直接选「后置主摄」「前置摄像头」或「后置微距」。预览出现后点底部的「拍照」，JPEG 会保存到当前用户的「图片」文件夹。点工具栏中的镜头名可以切换镜头。封存的 dev12.5 完整镜像自带 `y7003`。[相机应用与验证记录](docs/QCAM.md) · [PipeWire 相机与应用授权](docs/CAMERA-PIPEWIRE.md)

国行 KMS 开发镜像采用 Debian 13 ARM64，包含首次设密屏幕键盘、三摄 PipeWire 接口、中英文输入、SSC 本机校准、Blueman，以及已分别完成 30 分钟 OpenGL 和 Vulkan 实机测试的 Adreno 候选内核。解包时可用同一台平板的原厂 Android 属性预配蓝牙地址。测试机已安装 dev12.6 平板组件，顶栏可调音量，屏幕键盘可随外接打字键盘的连接状态自动收起和恢复。两颗功放分别加载本机出厂校准后，用户确认桌面音量 40% 时 YouTube 持续出声、音量合适。完整组合镜像的实机启动仍待验证。[镜像组成与校验值](docs/BOARD-IMAGE.md) · [四项软件包的离线更新](docs/KEYBOARD-IMAGE.md) · [扬声器验证](docs/SPEAKERS.md) · [蓝牙地址准备](docs/PERIPHERALS.md#prepare-a-fresh-installation)

镜像沿用 dev10 的 Xorg 内屏尺寸修复。平板内核能读出 118 × 190 毫米，实机当前运行的原版 Xorg 向应用报告 0 × 0。dev10 的 ARM64 虚拟 DSI 测试在四个方向都读到了正确尺寸，并在 200% 缩放下通过了点按、双指滚动和捏合测试。[内屏尺寸原理与实测](docs/PANEL-GEOMETRY.md)

11 月 18 日的产品开发已新增 [桌面集成包与 ARM64 隔离验证](docs/PLATFORM-BUILD.md)、[GPU 故障假设表](docs/GPU-INVESTIGATION.md) 和 [硬件／传感器来源映射](docs/HARDWARE-MAP.md)。[962 个包的基础系统](docs/DEBIAN-SNAPSHOT.md) 已从经签名元数据验证的软件包全新构建，随后整合 30 个修复包与平台包，通过 ARM64 用户空间检查。该历史快照仍需刷新安全更新，完整启动镜像和新配置的实机验收尚未完成。

Python 使用 `uv` 管理。Windows 用于设备连接与仓库管理，Linux/WSL 用于 ARM64 构建。先阅读 [AGENTS.md](AGENTS.md)、[状态表](docs/STATUS.md) 和 [产品计划](docs/PRODUCT.md)。

[候选镜像 03](docs/BOARD-IMAGE.md) 已在电脑上从 EFI 启动到 systemd，核对了实际挂载的根分区和全部 993 个软件包。独立测试卡和临时 EFI 入口已通过双盘模拟。候选镜像仍须在 TB320FC_PRC 实机启动并验证能回到原系统。

```sh
uv run --python 3.13 --no-project python scripts/check-public-tree.py
```

静态检查不证明内核可启动或设备功能可用。公开仓库不包含私人备份、账号/密码/密钥、原始设备日志、唯一设备标识或原厂固件镜像。后续发布仍须逐项审计来源与再分发条件。
